# 最近1年で自分で調べて試したIT関連の取り組み


### 1. 始めたきっかけ
Webアプリケーション開発において、サーバー側の処理だけでなく画面側の動きまで一貫して理解し、「バックエンドとフロントエンドの双方を扱えるエンジニアになりたい」と考えたことがきっかけです。
また、両方の技術やデータの流れを把握しておくことで、チーム開発においても他の担当者と円滑に連携し、より質の高い開発ができるようになると考え、公式ドキュメントやYouTubeの技術解説動画を活用してLaravelとVue.js（Inertia.js）を独学で試すことにしました。

### 2. どこまで試したか
環境構築から始め、まずはLaravelの習得とチーム開発での実践を行い、その後さらにモダンなフロントエンド連携へと学習を広げました。

* **チームでの卒業制作におけるLaravelの実装（バックエンド担当）**
  独学で身につけたLaravelの知識を活かし、ルーティング設計やコントローラー・モデル（Eloquent ORM）の構築などバックエンド全般を担当し、以下の主要機能を実装しました。
  * ログイン・新規登録機能およびマイページ機能の開発
  * プロフィール画像の設定・表示機能の実装
  * 各スポットへのコメント投稿機能・新規スポット追加機能の実装
  * Middlewareを使用したアクセス制御（不正アクセス防止）の実装
* **Vue.jsを使ったUI構築（個人学習）**
  YouTubeの動画をもとに、タスクの追加・完了・削除が画面の再読み込みなしで即座に反映される「To-Doリスト」を制作しました。これにより、データと画面が連動して動く仕組みやコンポーネントの基礎を身につけました。
* **LaravelとVue.jsの連携（Inertia.jsの検証）**
  YouTubeの解説を参考に、環境構築から簡単なデータ表示・登録ができるサンプルアプリの作成まで試しました。LaravelのControllerからVue.jsのコンポーネントへInertia.jsを使ってデータを連携させる仕組みを実装したことで、APIを別途作成せずにSPAのようなな画面遷移ができることを確認しました。

### 3. 得られた効果
* **開発スピードと保守性の向上**：PHPネイティブでの開発と比較して、ルーティング・コントローラーによる処理の整理やデータベース操作（Eloquent ORM）、Middlewareによるアクセス制御の記述が大幅に簡略化され、チーム開発においても安全かつスピーディに機能実装を進めることができました。
* **バックエンド・フロントエンド間のスムーズな実装とUX向上**：Vue.jsとInertia.jsの仕組みを取り入れたことで、サーバー側から画面側へのデータ受け渡しが直感的になり、再読み込みのない快適なUIを効率よく開発できるようになりました。
